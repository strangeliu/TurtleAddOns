# 猎人追踪助手 (HunterTracker)

一个为猎人职业设计的追踪技能快捷切换插件。

## 功能特点

- 🎯 **快速切换追踪技能** - 点击按钮打开追踪选择菜单
- 🔍 **支持11种追踪/寻找技能** - 包含所有猎人追踪技能和专业寻找技能
- 🖼️ **技能图标显示** - 每个选项显示对应技能的图标
- 🖱️ **按住 ALT + 拖动** - 自由调整按钮位置
- 💾 **位置记忆** - 自动保存按钮位置
- 📱 **透明界面** - 只显示图标和文字，不遮挡游戏画面

## 使用方法

| 操作                | 功能              |
| ----------------- | --------------- |
| **左键点击按钮**        | 打开/关闭追踪选择菜单     |
| **按住 ALT + 拖动按钮** | 移动按钮位置          |
| **点击菜单选项**        | 施放对应追踪技能，菜单自动关闭 |

## 命令

| 命令    | 功能       |
| ----- | -------- |
| `/ht` | 打开追踪选择菜单 |

## 安装方法

1. 下载插件压缩包
2. 解压到 `World of Warcraft/_retail_/Interface/AddOns/` 目录
3. 确保目录结构为 `Interface/AddOns/HunterTracker/`
4. 启动游戏，在角色选择界面确认插件已启用
